# Aligned Creation Engine (ACE)
> **Aligned Creation Engine** — Bridging conscious intent and physical execution through a guided 7-stage manifestation current.

## Overview
**The Creation Engine** is a full-stack web application designed to help creators, entrepreneurs, and individuals take abstract goals and ground them into physical reality. Mapped to the 7-chakra manifestation pipeline (Crown to Root), each intention moves through dedicated energetic and practical stages: purpose clarity, sensory visualization, vocal truth, emotional receptivity, subconscious block dismantling (AI), creative sigil generation, and grounded micro-action tracking.

---

## Key Features
- **Intention Hub (Dashboard):** Track multiple active projects with real-time visual progress across the 7-node Alignment Spine.
- **Goal Blueprint Intake:** Structured onboarding assessing baseline alignment across energetic centers before generating a custom pathway.
- **Modular Chakra Workspaces:**
  - 👑 **Crown:** Core Purpose & "Why" Definition
  - 👁️ **Third Eye:** Sensory Goal Visualization & Ambient Focus Canvas
  - 🗣️ **Throat:** Affirmation & Solfeggio Resonance Module
  - 💚 **Heart:** Receptivity & Gratitude Logging
  - ☀️ **Solar Plexus:** Subconscious Block Breaker & AI Cognitive Reframer
  - 🎨 **Sacral:** Algorithmic Geometric Sigil Generator
  - 🌍 **Root:** Earth-Anchor Habit & Milestone Action Checklist
- **Controlled Freedom Flow:** Guided downward cascade from vision to execution, with the flexibility to jump into active bottlenecks at any time.

---

## Tech Stack
- **Frontend:** Semantic HTML5, Modern CSS (Custom Properties, Flexbox, CSS Grid), Vanilla JavaScript (ES6+)
- **Backend / API:** PHP (Session handling, RESTful API routing, secure AI proxy)
- **Database:** MySQL / MariaDB (Prepared statements via PDO)
- **Design System:** Custom dark-mode aesthetic with dedicated CSS color tokens for each chakra frequency
